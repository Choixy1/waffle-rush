# 와플 대소동

친구와 함께 와플과 쉐이크를 만드는 3D 요리 게임이에요. 로그인 없이 브라우저에서 바로 할 수 있어요.

- 혼자 하기, 맵 만들기, 내 맵 저장 (이 브라우저에 저장)
- 같이 하기: 최대 4명, 방 코드 4자리로 들어와요 (브라우저끼리 직접 연결, PeerJS)
- 맵 주고받기: 맵 고르기에서 "코드 복사" → 친구가 "코드로 불러오기"

## 파일
- `index.html` 게임 전체 (빌드 결과)
- `peerjs.min.js` 같이 하기 연결 라이브러리 (PeerJS 1.5.5, MIT)
- `source/` 원본 코드. `python3 source/build_site.py`로 `index.html`을 다시 만들어요.
